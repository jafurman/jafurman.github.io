What I have been building since 2024

This page last went up in May 2024. Here is what happened after that.

Job Scout — the 2024 job crawler, finished

The project above, rebuilt for the browser as a single ~80 KB file you can email someone. It ranks postings against your résumé with TF-IDF cosine similarity, and with local AI embeddings (all-MiniLM-L6-v2 through transformers.js) when Smart matching is on. Your résumé text never leaves the machine.

A two-GPU local AI rig, and what it runs

An RTX 5060 Ti 16 GB and an RTX 3060 12 GB driven together with 128k context, fully offline. I measured the layouts and wrote up which split gives which speed, then put the rig to work as a coding partner that never sends my code to anyone.

70+ browser games built with that rig

A library of browser games and experiments — brawlers, racers, FPS, survival, platformers — each one starting from a written spec (genre, loop, twist) before any code, and each one playable in a browser. The 2D platformer with procedural generation above is where that pipeline grew from.

Smudge Aquarium — a real .NET desktop app

WPF on .NET 8 with a separate simulation core (fish behaviour, food, lighting, day/night) that has its own test project, and a UI layer that draws 3D-shaped fish in a 2.5D tank. It runs on this desktop and on the Raspberry Pi below.

The Raspberry Pi hub screen

A 24/7 Raspberry Pi with a 7-inch touch hub (Kivy, 1024×600): scene backgrounds you pick from the screen, an animated cat that walks on the scene's own ledges, an aquarium display, and a page of the browser games so the family can play them from a phone.

Tools that actually get used

Small apps I run daily rather than demos: a résumé-aware job scout, a notes board, a photo editor, a budget tracker, a tip splitter, a PC-local web browser front end, and a Minecraft mod.
